# Slicer Selector

This is the homebrew package for SlicerSelector

All code is in this repo: https://github.com/spuder/SlicerSelector

Upon push of a new tag to https://github.com/spuder/SlicerSelector, a github actions runs that will update the version in this repo. 


## Installation

```
brew tap spuder/SlicerSelector
brew install slicer-selector
```
